# CI/CD Lab

![CI](https://github.com/your-user/ci-cd-lab/actions/workflows/ci.yml/badge.svg)

A minimal Python project for CI/CD practice.

## Structure
- app/main.py
- tests/test_main.py
- .github/workflows/ci.yml
- requirements-dev.txt

## Workflow capabilities
- Smoke check
- Flake8 lint
- Pytest
- Python matrix: 3.11 / 3.12
- Pip cache
- Manual trigger
- Path filters
- Concurrency control
- Artifact upload
